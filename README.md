# TechShop

Trabajo práctico final del Seminario de Angular.

Es una tienda de electrónica hecha con Angular. Se puede ver un catálogo de
productos (smartphones, laptops, tablets y accesorios) que se traen de una API,
agregarlos a un carrito y después completar un formulario para finalizar la
compra. También tiene una página con información de la tienda.
